# Content Idea Calendar Template

## Purpose
The content idea calendar is a high-level planning tool that comes BEFORE creating full blueprints. It allows for quick ideation, review, and approval of content concepts.

## Content Idea Structure

Each content idea contains:

### 1. Internal Title
- Format: lowercase-with-dashes
- Used for file naming and internal reference
- Example: "5-tennis-tricks-you-need"

### 2. Topic
- What the video is about (1-2 sentences)
- Descriptive but not the full script
- Example: "Five essential tennis tricks that improve your game instantly"

### 3. Clickbait Overlay
- 3-6 words maximum
- Bold, scroll-stopping text
- Appears on screen as overlay
- Example: "5 Tennis Tricks You Need"

### 4. Hook Sentence
- Spoken opening line
- Must follow mass-first, niche-later principle
- Triggers emotion + curiosity gap
- Example: "You're losing games because you're missing these five tricks"

### 5. Keywords
- 3-5 keywords the video focuses on
- For SEO and topic clarity
- Example: ["tennis tips", "improve tennis game", "tennis techniques", "beginner tennis", "tennis tricks"]

### 6. Products Mentioned
- Array of products with names and links
- Format: [{ name: "Wilson Pro Staff", url: "https://..." }]
- Empty array if no products

### 7. Context/Script Notes
- Context needed for scriptwriting
- If hook mentions specific things (like "5 tricks"), LIST THEM HERE
- Include sources if applicable
- Example: "The 5 tricks are: 1. Continental grip for serves, 2. Split-step timing, 3. Follow-through technique, 4. Court positioning, 5. Topspin backhand. Source: Tennis Magazine April 2024"

### 8. Sub-Niche
- One of the 5 sub-niches from brand overview
- Example: "Tennis Fundamentals"

### 9. Post Type
- "value-only" - Pure educational content, no CTA
- "soft-engagement-cta" - Follow for more, save this, etc.
- "hard-conversion-cta" - Link in bio, shop now, etc.

### 10. Status
- "pending" - Awaiting review
- "approved" - Ready for blueprint creation
- "rejected" - Not moving forward

## Content Mix Guidelines

Recommended distribution:
- **50%** Value-only
- **30%** Soft engagement CTA
- **20%** Hard conversion CTA

Adjust based on brand goals and audience maturity.

## Review Process

1. **Generate** ideas using AI with brand context
2. **Review** using swipe interface (approve/reject/edit)
3. **Edit** if needed to refine details
4. **Approve** ideas that fit brand and goals
5. **Export** approved ideas to Excel
6. **Generate** full blueprints from approved ideas
